# Атомные привычки - Backend API Трекера Привычек 🏃‍♂️ Habit Tracker

Бэкенд-часть SPA веб-приложения для трекера полезных привычек, разработанная на основе бестселлера Джеймса Клира «Атомные привычки». Проект реализует логику формирования привычек, их валидацию, защиту персональных данных, постраничный вывод и автоматические напоминания пользователям в мессенджер Telegram по расписанию.

## 🛠 Технологический стек

* **Язык разработки:** Python 3.12
* **Фреймворк:** Django 5.0+ & Django REST Framework (DRF)
* **Аутентификация:** JWT (django-rest-framework-simplejwt)
* **Асинхронные задачи и планировщик:** Celery & Celery Beat
* **Брокер сообщений / Кэш:** Redis
* **Безопасность:** Django CORS Headers, Django Environ
* **Документация:** drf-yasg (Swagger / ReDoc)
* **Тестирование:** Coverage, APITestCase

## 🏗 Ключевая бизнес-логика и валидаторы

В соответствии с методологией книги, модель привычки содержит жесткие правила, которые проверяются на уровне сериализаторов:
1. **Исключение дублирования вознаграждения:** Нельзя одновременно выбрать связанную приятную привычку и текстовое вознаграждение. Можно заполнить только одно из двух полей.
2. **Ограничение по времени:** Время на выполнение привычки должно быть не больше **120 секунд (2 минут)**.
3. **Фильтр связей:** В качестве связанных привычек могут выступать только те объекты, у которых установлен флаг приятной привычки (`is_pleasant=True`).
4. **Ограничения для приятных привычек:** Сама приятная привычка не может иметь своего вознаграждения или своей связанной привычки.
5. **Регулярность:** Привычку нельзя выполнять реже, чем 1 раз в 7 дней (периодичность от 1 до 7 дней).

## 🚀 Пошаговое руководство по локальному запуску

### 1. Клонирование и подготовка окружения
Убедитесь, что у вас установлен Python, PyCharm и запущен сервер **Redis** (на стандартном порту `6379`).

```bash
# Клонируйте репозиторий
git clone https://github.com
cd habit_tracker

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл **`.env`** в корневой папке на основе шаблона `.env.template` и заполните своими данными:
```env
# Django настройки
SECRET_KEY=your_django_secret_key
DEBUG=True

# Настройки базы данных PostgreSQL
DB_NAME=open_lms
DB_USER=postgres
DB_PASSWORD=your_postgres_password
DB_HOST=127.0.0.1
DB_PORT=5432

ALLOWED_HOSTS=localhost,127.0.0.1
CELERY_BROKER_URL=redis://localhost:6379/0
CELERY_RESULT_BACKEND=redis://localhost:6379/0
TELEGRAM_BOT_TOKEN=токен_вашего_телеграм_бота
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
```

### 3. Миграции и создание суперпользователя
```bash
# Подготовьте и примените миграции базы данных
python manage.py makemigrations
python manage.py migrate

# Создайте администратора (в качестве логина используется Email)
python manage.py createsuperuser
```

### 4. Запуск сервисов
Для полноценной работы приложения вам потребуется запустить три параллельных процесса в разных терминалах PyCharm:

```bash
# Терминал 1: Запуск Django веб-сервера API
python manage.py runserver

# Терминал 2: Запуск Celery Worker (выполнение задач)
celery -A config worker --loglevel=info

# Терминал 3: Запуск Celery Beat (планировщик ежеминутных напоминаний)
celery -A config beat --loglevel=info
```

## 📂 Структура основных эндпоинтов

* `POST /api/users/register/` - Регистрация нового пользователя.
* `POST /api/users/token/` - Получение JWT-токена (авторизация).
* `POST /api/users/token/refresh/` - Обновление JWT-токена.
* `GET /api/habits/` - Список привычек текущего пользователя (с пагинацией по 5 элементов).
* `POST /api/habits/` - Создание новой привычки.
* `GET /api/habits/<id>/` - Просмотр конкретной привычки (доступно только владельцу).
* `PUT/PATCH /api/habits/<id>/` - Редактирование привычки (доступно только владельцу).
* `DELETE /api/habits/<id>/` - Удаление привычки (доступно только владельцу).
* `GET /api/public/` - Список всех публичных привычек (доступен всем для чтения).
